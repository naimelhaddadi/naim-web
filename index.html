// Sobre mí

No aprendo para aprobar.
Aprendo para entregar.

Estudio 1º de Grado Superior en Desarrollo de Aplicaciones Web, pero el aula es solo la mitad. La otra mitad la construyo yo: leyendo documentación, rompiendo cosas en mi VPS y desplegando software que un cliente real usa todos los días.

Mi enfoque no es la tecnología por la tecnología — es resolver problemas concretos de negocio: dónde se está perdiendo dinero, qué proceso manual se puede automatizar, qué dato no está llegando a quien lo necesita. 01
Caso de estudio principal · En producción

Sistema Autónomo de Captación & Retención para Clínica Dental

Cliente real · Madrid + Valladolid · 2 sedes · Activo 24/7

live

Una clínica dental con dos sedes perdía leads cada día por procesos manuales: agendamientos olvidados, recordatorios sin enviar, reseñas sin pedir. Diseñé, construí y desplegué yo mismo un sistema autónomo que gestiona todo el ciclo del paciente sin que nadie tenga que tocarlo.

1
/ El problema del cliente
Leads que se perdían

Pacientes que pedían información por WhatsApp y nunca recibían respuesta a tiempo — se iban a la competencia.

Ausencias sin gestión

Sin recordatorios automáticos, una franja de citas perdidas equivale a horas de sillón vacías al mes.

Reseñas no capturadas

Pacientes satisfechos que se iban sin dejar reseña — la reputación online no crecía pese al buen servicio.

2
/ Mi solución técnica

Arquitectura de 3 capas, desplegada en un VPS propio bajo Docker. El stack está migrando este verano de n8n a Python puro (FastAPI) + frontend JS — la versión a septiembre 2026 será la siguiente:

/ frontend

Panel ligero en JS vanilla que consume la API del backend con Fetch + Async/Await. La clínica ve métricas en tiempo real y dispara campañas desde aquí.

/ backend python

API REST en FastAPI que orquesta WhatsApp Cloud API, agenda, recordatorios y captura de reseñas. Integración con LLMs para clasificar mensajes entrantes.

/ infraestructura

VPS propio bajo Docker: contenedores aislados para API, base de datos y workers. Nginx + SSL/HTTPS y backups automáticos. Lo despliego yo de extremo a extremo.
