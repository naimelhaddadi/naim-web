03Personal project

GameStore

A structured Java backend, layer by layer.

Type
Java · Spring Boot REST API
Architecture
Controller · Service · Repository · DTO

  1. The goal

    Not just endpoints that work: a backend whose structure still holds when it grows.

  2. The approach

    One job per layer: the controller speaks HTTP, the service holds the rules, the repository talks to the database, and DTOs shape what goes out.

  3. The system

    Spring Boot with Spring Data JPA, Bean Validation on input and unit tests with JUnit 5 and Mockito. Pick an endpoint to follow a request through the layers.

Technology
