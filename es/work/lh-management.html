LH Sport & Entertainment Management

  1. 01Problema

    Información sin un sistema.

    Una agencia deportiva internacional maneja mucha información conectada (jugadores, clubes, contratos, agentes) y necesitaba un único sitio donde todo encajara.

  2. 02Modelo de datos

    Primero el dominio, después las pantallas.

    Más de 10 entidades, entre ellas jugadores, contratos, traspasos, agentes, clubes y ligas, y sobre todo cómo se relaciona cada una con las demás.

  3. 03Base de datos

    Construida desde cero en SQL Server.

    Lideré el equipo que diseñó e implementó el esquema relacional desde cero. Es la base sobre la que la agencia trabaja cada día.

  4. 04Lógica de negocio

    Reglas que los datos no pueden romper.

    Los procedimientos almacenados y los triggers de T-SQL mantienen la integridad referencial dentro de la propia base de datos y automatizan tareas que el equipo hacía a mano.

  5. 05Interfaz web

    Donde el trabajo diario se encuentra con los datos.

    Una interfaz web de captura de datos conectada a la base de datos en tiempo real. Le ahorra al equipo unas dos horas de trabajo manual al día.

  6. 06Resultado

    En uso cada día. Con recomendación.

    La agencia trabaja con la base de datos cada día, y salí del puesto con una carta de recomendación oficial de la dirección.
